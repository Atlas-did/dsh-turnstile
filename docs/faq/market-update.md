# 插件更新报错「更新前的构件未能验证」

**症状**：插件市场里点更新，两秒就报错，原话是「更新前的构件未能验证」之类。

**原因**：插件已安装时，harness 不允许**再装一遍**；而某些版本的插件市场，更新动作就是「再装一遍」。
所以错的不是你的网络，是那条更新路径。

**修法**（= 卸载后重装，带事务）：

```
node tools/manage.mjs <profileDir> --list      # 先看清装了什么、行 id 是什么
pnpm remove <包名>                              # 在 profile 目录里执行
pnpm add <包名|file:路径>                       # 重新装
node tools/preflight.mjs <profileDir>           # 12 项检查，确认没留下冲突
```

**不能提前预测**：判定逻辑在插件市场内部，我们只能事后修。这条写在这里，避免以后误以为工具漏了。
