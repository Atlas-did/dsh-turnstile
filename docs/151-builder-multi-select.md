# 页面搭建器：多选与批量编辑

## 用户流程

- 普通点击：选中一个节点。
- Ctrl／Cmd + 点击：加入或移除一个节点。
- Shift + 点击：从选择锚点扩展到画布树中的连续范围。
- 多选后，右侧只显示所有节点兼容的共同属性和共同样式。
- 值不一致时显示「多个值」，不会把第一个节点的值冒充成所有人的值。
- 批量修改后继续保存、预览或导出，使用的是同一份当前页面。

## 数据契约

`page-model.js` 新增两个命令：

```js
{ type: 'setPropMany', nodeIds: ['heading-1', 'text-2'], key: 'text', value: '统一文字' }
{ type: 'setStyleMany', nodeIds: ['heading-1', 'text-2'], key: 'align', value: 'center' }
```

命令复用单节点的 `setProp` / `setStyle` 声明校验，不另写一套类型、枚举或范围规则。所有修改只作用于局部副本；任一节点不存在、不支持该字段或值非法时，整个命令抛错，输入页面不变。

重复节点 id 会被去重，空选择会被拒绝。属性 schema 只有在类型、枚举选项和数值范围兼容时才进入共同字段；标签或默认值不同不妨碍批量编辑。

## 历史与撤销

一次批量命令只产生：

- 一个 `past` 步骤；
- 一个自动快照；
- 一个带「批量修改属性／样式 · 字段（N 个节点）」标签的时间线步骤。

撤销一次恢复所有节点的旧值，重做一次恢复所有节点的新值。多选状态在批量编辑后保留；历史回退导致节点不存在时，会清理无效选择，全部失效则回退根节点。

无实际变化的命令不进入撤销栈或时间线，避免下一步撤销跳到更早的编辑。

## 验收

`plugins/turnstile-popup/test/page-model.test.mjs` 新增 8 项断言，覆盖批量属性、批量样式、输入不可变、单步撤销／重做、原子失败和空选择。

`npm run test:builder` 使用真实 Edge 操作覆盖：

- Ctrl 多选、选中高亮与 Shift 范围选择；
- 混合值标记；
- 批量文字和批量对齐实际到达所有渲染节点；
- 一次批量修改只增加一个历史步骤；
- 一次撤销／重做恢复整组值；
- 修改后保存、刷新、恢复与导出仍使用同一页面。
