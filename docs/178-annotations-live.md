## 途中发现的一个排查坑

第一次在 mini 上找不到批注入口，原因是把带 token 的 URL 直接当页面打开了——那是 DSH 自己的 Web UI。
正确路径要保留 token 并改 pathname：`/turnstile/console?token=...`
