## 3. 全屏模式的边界（重要）

能做到：`requestFullscreen()` 让页面全屏（能盖住任务栏），Esc 退出。

做不到：**隐藏 DSH 自己的顶栏/侧栏**——那是 Electron 主进程渲染的，页面内改不了。
要做那一步，必须改主进程（另一个量级），不是插件能力范围。

## 4. ctx.windows 的实现定位

不是原生绑定，是「一个常驻 PowerShell + UIA 进程被所有插件共用」：
首次调用含握手 1253ms，之后每次 ~192ms。要 ms 级必须上原生模块。
