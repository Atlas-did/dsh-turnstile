# 页面搭建器：大纲树与键盘操作

## 用户流程

左侧「页面大纲」按真实父子层级列出组件，显示中文组件名、类型和缩进。大纲与画布共享同一份选择状态：

- 点击大纲行会选中同一个画布节点，右侧检查器同步更新。
- Ctrl／Cmd + 点击、Shift + 点击继续复用 `selection.js`，不会出现大纲与画布各自一套多选规则。
- 折叠按钮只隐藏大纲后代，不删除画布内容；折叠、展开、焦点和 hover 都不进入编辑历史。
- 画布节点和大纲行均可聚焦，Enter／Space 可选择；方向键按画布的深度优先顺序移动单选选择。

## 快捷键

| 操作 | 快捷键 | 约束 |
|---|---|---|
| 撤销 | Ctrl／Cmd + Z | 走现有 `moveHistory(-1)` |
| 重做 | Ctrl + Y，或 Ctrl／Cmd + Shift + Z | 走现有 `moveHistory(1)` |
| 保存 | Ctrl／Cmd + S | 调用现有保存路由，并阻止浏览器保存框 |
| 删除节点 | Delete／Backspace | 仅限单选、非根节点、焦点位于画布或大纲 |
| 上一个／下一个节点 | ArrowUp／ArrowDown | 仅限单选和画布／大纲上下文 |
| 取消组件放置 | Escape | 清除 `pendingType`，不制造编辑步骤 |

输入框、文本域、下拉框和 contenteditable 中不会触发删除、撤销、重做或方向键导航。Ctrl／Cmd + S 仍可从属性输入框保存当前页面。

多选删除目前明确拒绝并提示先单选，不会循环调用删除命令制造多条历史。删除按钮和 Delete／Backspace 共用 `deleteSelected()`，因此选择回退、状态提示、撤销和重做一致。

## 实现边界

- 大纲文字全部通过 `textContent` 写入，组件属性不会作为 HTML 注入。
- 画布重新渲染后，焦点恢复到当前主选节点；不会无条件把焦点从属性输入框抢回画布。
- 删除、保存、撤销和重做继续经过原有页面模型、历史时间线和 HTTP 路由，没有新增第二份页面状态。
- 大纲折叠集合是单独的瞬态 UI 状态，不写入页面文件或快照。

## 验收

`npm run test:builder` 使用真实 Edge、鼠标和键盘事件覆盖：

- 大纲行数与画布节点一致，点击与 Ctrl 多选双向反映到画布高亮；
- 多选删除被拒绝且不增加历史；
- 折叠／展开不改变历史；
- Enter／Space 选择、ArrowDown／ArrowUp 导航及焦点恢复；
- 新增统计节点后 Delete 删除、Ctrl+Z 恢复、Ctrl+Y 再删除；
- 属性输入框聚焦时 Delete 不删除节点；
- Ctrl+S 发出真实 POST 保存，之后导出仍使用同一份当前页面；
- 无未捕获浏览器脚本错误。

当前结果：**61／61 通过**。证据限于隔离副本、临时 HTTP 服务和浏览器夹具，**不等于真实 mini 或桌面端端到端验收**。
