# 提示条按视图分化（01-D 收尾，2026-11-02）

之前只有总览有提示条，且所有视图共用门禁结论。现在每个视图讲自己的事实：

| 视图 | 结论 | 影响 | 主按钮 |
|---|---|---|---|
| 总览 | 未观测 / 发现阻塞 N 项 / 检查通过 | 只有已运行的检查才算数 | 查看门禁检查 |
| 插件 | 配置里停用 N 个插件 | 停用不等于卸载，改完要重启 | 查看门禁检查 |
| UI 占用 | N 个 UI 面被多个插件共享 | 共享声明 ≠ 已发生视觉冲突 | 查看深层架构 |

三条影响句都在明确「这个结论不覆盖什么」——这正是原始方案要求的口径。
