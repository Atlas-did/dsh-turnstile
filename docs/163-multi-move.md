# 多选结构化移动（2026-11-01）

handoff P1 最后一项编辑能力：多选时 Alt+↑/↓ 现在能整体上下移动，仍然**一次一个历史步骤**。

## 规则（故意收窄）

| 情况 | 行为 |
|---|---|
| 同父级、2 个以上节点、向上/下 | 整体移动一格 |
| 到边界 | 明确拒绝「已到同级顺序的边界」 |
| 跨父级 | 明确拒绝「只支持同一父级下的批量移动」 |
| 少于两个 | 明确拒绝「批量移动至少选择两个节点」 |
| 多选 + Alt+←/→ | 提示「多选只支持上下移动；改层级请先单选」 |

**为什么不做跨父级批量**：那会同时改变层级和顺序，用户很难预期结果；宁可拒绝并说明。

## 实测

```
ok  两个节点整体下移一格   CAB

ok  到边界时明确拒绝      已到同级顺序的边界
ok  跨父级明确拒绝        只支持同一父级下的批量移动
ok  少于两个明确拒绝      批量移动至少选择两个节点
MOVE_MANY_OK
```
